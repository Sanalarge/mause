# Security policy

## Supported versions

Mause is in early development. Security fixes are applied to the latest release and the current `main` branch.

## Reporting a vulnerability

Do not create a public issue for a suspected vulnerability. Open the repository's **Security** tab, choose **Advisories**, then select **Report a vulnerability** to submit a private GitHub Security Advisory.

Include the affected version, operating system, reproduction steps, expected impact and any proof of concept that helps validate the report. Remove personal data, credentials and unrelated device information.

The maintainers will acknowledge a complete report as soon as practical, investigate it privately and coordinate disclosure after a fix is available. Please do not publish details before that coordination is complete.
