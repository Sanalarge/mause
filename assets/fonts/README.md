# Yazı tipleri

Mause derleme sırasında bu dosyaları gömer; çalışırken hiçbir yazı tipi indirilmez.

- `Poppins-Regular.ttf`, `Poppins-Medium.ttf`, `Poppins-SemiBold.ttf`: Poppins (arayüz 400 / 500, başlıklar ve "mause" kelime işareti 600). Kaynak: [google/fonts, ofl/poppins](https://github.com/google/fonts/tree/main/ofl/poppins). Lisans: [OFL-Poppins.txt](OFL-Poppins.txt).
- `Phosphor-Regular.ttf`: Phosphor Icons, Regular ağırlık (arayüz simgeleri). Kaynak: [@phosphor-icons/web 2.1.1](https://github.com/phosphor-icons/web). Lisans: MIT, [MIT-Phosphor.txt](MIT-Phosphor.txt).

Poppins SIL Open Font License 1.1 ile dağıtılır. Pencere düğmeleri Rust kaynağında çizilir.
